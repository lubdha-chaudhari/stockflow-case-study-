# StockFlow – Backend Case Study (Bynry)

This repository contains my solutions for the Backend Engineering Intern case study for Bynry.  
The objective was to review existing backend code, design a scalable database schema, and implement an API while working with incomplete requirements.

---

## Structure

- `part1_code_review.md` – Code review, issue identification, impact analysis, and corrected implementation
- `part2_database_design.md` – Database schema design, assumptions, and trade-offs
- `part3_api_design.md` – Low-stock alerts API implementation with edge cases and assumptions

---

## Key Focus Areas

- Backend correctness and safety
- Data integrity and scalability
- Handling real-world ambiguity
- Clear documentation of assumptions

---

## Assumptions

Since some requirements were intentionally incomplete, assumptions were made and clearly documented in each part.

---

## Time Spent

~90 minutes total, aligned with the case study instructions.

---

## Notes

The solutions prioritize clarity, correctness, and maintainability over over-engineering.
